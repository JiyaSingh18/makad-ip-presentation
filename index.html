Copyright · Makad

Copyright — Makad's creative assets

IP concept

What is copyright?

Legal right over original works fixed in a medium — code, art, audio. Automatic on creation (§13, Copyright Act 1957). Human author required — not AI alone (Thaler 2023).

In Makad

Our copyrightable works (authors: Jiya Singh & Meet Jain)

  • Astromech audio — A-wake-rise, A-affirm, A-laugh…
  • 19 head motions — storyboard v0.2 keyframes
  • Face animations — E-neutral, E-laugh, E-gaze…
  • Expression composer — firmware + coordination logic
  • Docs & renders — vision, 14 specsheets

Patent · Makad

Patent — could Makad's inventions qualify?

IP concept

What is a patent?

20-year monopoly on a novel, non-obvious invention (Patents Act 1970). Must pass novelty + inventive step. Prior art defeats claims. Search: USPTO, ipindia.gov.in.

In Makad

Patent candidates & my evaluation

  • 3-axis head in 60 mm neck, ~250 g on floor droid
  • Expression composer — 4-channel coordinated output
  • Prior art: Cozmo-class robots, Plos One 2024
  • Decision: document in specs; filing only if RP-01 proves novelty

Research papers — prior art in Makad's design

IP concept

Role of research papers in IP

Published work becomes prior art — limits patent novelty. Citing ≠ copying. Author holds paper copyright; you create original implementation.

  • Journal sources: Plos One, IEEE, ACM
  • Blocks identical patent claims

Industry Product · Makad

Anki Vector — industry IP lesson for Makad

IP concept

Why study a commercial product?

A product bundles patents, trademarks, trade secrets, copyrighted code. Its lifecycle shows which IP survives company failure.

Case study → Makad

Anki Vector (2018–2019)

  • AI companion — cloud NLU, expressive face — same category as Makad
  • Bankrupt 2019 → servers offline → robots lost personality
  • IP sold to Digital Dream Labs — patents, TM, codebase transferred
  • Wire-Pod revived robots only after DDL open-sourced code

For Makad: character IP (animations, sounds) = survival asset. Own expression layer via copyright.

Landmark Case · Makad

Thaler v. Perlmutter — AI authorship & Makad

Landmark case (2023)

Can AI be an author?

Dr. Thaler sought copyright on AI-generated image. Refused. Human creativity required.

  • USCO AI Guidance 2023: AI-assisted OK
  • WIPO IP & AI Toolkit 2024: same globally
In Makad's AI/ML stack

Which layers are protectable?

  • Cloud STT output — not mine; provider ToS
  • Animations, sounds, motions — human-authored → copyrightable
  • Composer code — my design → copyrightable
  • AI = pipeline tool — not author of expressive works

Git history + 31K docs prove human authorship for Makad.
